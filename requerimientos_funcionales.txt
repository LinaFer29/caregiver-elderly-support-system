RF-01 Gestión de actividades predefinidas

Descripción:
El sistema debe permitir al administrador registrar, consultar, actualizar y eliminar actividades predefinidas que serán utilizadas posteriormente por los cuidadores al momento de construir rutinas para los adultos mayores.

Actor:
Administrador.

Precondiciones:
- El administrador debe contar con credenciales válidas de acceso al sistema.
- El administrador debe haber iniciado sesión en el panel de administración.

Flujo principal:
1. El administrador accede al módulo de administración del sistema.
2. El administrador consulta el listado de actividades existentes.
3. El administrador selecciona la opción para crear, editar o eliminar una actividad.
4. El sistema registra la operación realizada.
5. El sistema actualiza el catálogo disponible de actividades.

Postcondiciones:
- La actividad queda registrada, modificada o eliminada según la acción ejecutada.
- El catálogo de actividades disponible para la planificación de rutinas queda actualizado.

RF-03 Registro de cuenta de cuidador

Descripción:
El sistema debe permitir a una persona registrarse como cuidador mediante el ingreso de sus datos personales y de acceso, para habilitar el uso de la plataforma.

Actor:
Cuidador.

Precondiciones:
- El cuidador no debe tener una cuenta activa registrada con las mismas credenciales exigidas por el sistema.

Flujo principal:
1. El cuidador accede al formulario de registro.
2. El cuidador ingresa su información personal y de acceso.
3. El cuidador confirma el envío del formulario.
4. El sistema valida la información suministrada.
5. El sistema registra la cuenta del cuidador.

Postcondiciones:
- La cuenta del cuidador queda creada en el sistema.
- El cuidador puede proceder a iniciar sesión.

RF-15 Creación de rutinas para un adulto mayor

Descripción:
El sistema debe permitir al cuidador crear rutinas para un adulto mayor, seleccionando actividades predefinidas y configurando su programación.

Actor:
Cuidador.

Precondiciones:
- El cuidador debe haber iniciado sesión.
- Debe existir un adulto mayor activo seleccionado.
- Deben existir actividades predefinidas registradas en el sistema.

Flujo principal:
1. El cuidador accede al formulario de creación de rutinas.
2. El sistema muestra el catálogo de actividades disponibles.
3. El cuidador selecciona una o varias actividades.
4. El cuidador define la fecha de inicio y, cuando corresponda, la fecha de fin.
5. El cuidador configura para cada actividad su hora, frecuencia, estado e instrucciones adicionales.
6. El sistema valida la información ingresada.
7. El sistema registra la rutina y sus ocurrencias programadas.

Postcondiciones:
- La rutina queda creada y asociada al adulto mayor seleccionado.

RF-23 Recepción de recordatorios de actividades

Descripción:
El sistema debe notificar al adulto mayor cuando exista una actividad programada pendiente de realizar.

Actor:
Adulto Mayor.

Precondiciones:
- Debe existir una actividad programada para el adulto mayor.
- La hora programada de la actividad debe haber sido alcanzada.

Flujo principal:
1. El sistema identifica una actividad programada.
2. El sistema genera un mensaje de voz.
3. El dispositivo reproduce el recordatorio al adulto mayor.

Postcondiciones:
- El adulto mayor recibe la notificación de la actividad correspondiente.

Actor:
Adulto Mayor.

- Debe existir una actividad programada.
- La actividad puede contener instrucciones adicionales.

Flujo principal:
1. El sistema recupera la información de la actividad.
2. El sistema genera el mensaje de voz correspondiente.
3. El dispositivo reproduce la información al adulto mayor.

Postcondiciones:
El adulto mayor recibe las instrucciones necesarias para realizar la actividad.


RF-25 Registro de respuesta del adulto mayor

Descripción:
El sistema debe permitir que el adulto mayor responda a un recordatorio mediante comandos de voz.

Actor:
Adulto Mayor.

Precondiciones:

El adulto mayor responde al recordatorio.

El sistema procesa la respuesta.
El sistema registra el estado correspondiente de la actividad.

Postcondiciones:
La respuesta del adulto mayor queda almacenada en el sistema.
